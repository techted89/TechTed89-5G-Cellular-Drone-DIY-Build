Single Board Computers (SBC) — Companion Computer

The SBC runs the 5G modem, WebRTC video encoder, MAVLink bridge, Tailscale mesh, REST API, SMS beacon, and optional game-controller input. Choose based on your AI/ML, video encoding, and budget needs.

Raspberry Pi 5 (8GB)

$80–$100
  • CPU: Broadcom BCM2712, 2.4GHz quad-core ARM Cortex-A76
  • RAM: 8GB LPDDR4X
  • Expansion: PCIe Gen 2 x1, 2x micro-HDMI, CSI x2, DSI x2
  • Video: Hardware H.264/H.265 encode (V4L2M2M)
  • Pros: Massive ecosystem, cheap, tons of HATs, great driver support
  • Cons: No NVMe boot on older firmware (fixed on Pi 5), 5V/5A power needed, throttles without active cooling
  • Drone fit: Best overall value for 5G + WebRTC + MAVLink bridge
Buy Pi 5

NVIDIA Jetson Orin Nano Super

$249
  • CPU: ARM Cortex-A78AE (6-core)
  • RAM: 8GB LPDDR5
  • GPU: 1024-core Ampere, 67 TOPS AI
  • Video: NVDEC/NVENC hardware H.264/H.265, 4K60
  • Pros: Onboard AI/ML (object detection, avoidance), hardware video encode, PCIe Gen 4
  • Cons: Expensive, larger power draw, bigger footprint
  • Drone fit: BVLOS with onboard AI, obstacle avoidance, precision landing
Buy Jetson

Odroid M1S

$87

  • RAM: 4GB or 8GB LPDDR4X
  • Expansion: M.2 M-key (NVMe), PCIe 2.1, Gigabit Ethernet
  • Video: Hardware H.264/H.265 encode/decode
  • Pros: M.2 NVMe boot, low power, eMMC option, good thermal design
  • Cons: Smaller community than Pi, fewer camera HATs
  • Drone fit: Low-power long-endurance builds, NVMe storage for logs

  • Expansion: M.2 PCIe 2.1, eSATA, Gigabit Ethernet

Flight Controllers (FC) — Split-Brain Architecture

The FC handles low-level motor control, sensor fusion, and failsafe execution. In this project's split-brain design, the FC runs ArduPilot/PX4 and talks MAVLink over serial to the SBC. You can use a commercial autopilot or design a custom FC board.

Holybro Pixhawk 6C

$199–$300
  • MCU: STM32H743 (480 MHz)
  • Sensors: Triple IMU, dual barometer, temperature-compensated
  • IO: 5x UART, CAN, I2C, SPI, PWM outputs
  • Firmware: ArduPilot, PX4
  • Pros: Open-source standard, proven reliability, great docs, RTK-ready
  • Cons: Expensive for hobby builds, larger than AIO stacks
  • SBC interface: TELEM2/TELEM4 serial @ 921600 baud to SBC

Custom FC Guide

Custom Flight Controller + Single SBC Design

For a truly integrated build, design a single PCB that combines:

  • FC MCU: STM32H743 or H753 running ArduPilot/PX4
  • SBC: Raspberry Pi CM4/CM5 or ODroid module on the same board
  • Interconnect: Internal UART/USB (no external wires, vibration-resistant)
  • Power: Shared 5V/3.3V regulators for both FC and SBC
  • Connectors: PWM out to ESCs, CAN, RC input, telemetry, GPS, battery monitor

Advantages: No vibration-prone serial cables between SBC and FC, smaller footprint, shared power, single mounting point.

Disadvantages: Single point of failure, harder to upgrade FC or SBC independently, requires PCB design skills.

5G / Cellular Modems — CGNAT Bypass

The drone connects through a Tailscale VPS mesh to bypass CGNAT. You need a 5G modem with a data SIM. eSIM enables remote carrier switching without physical access — critical for BVLOS.

Quectel RM520N-GL (eSIM)

$120–$180
  • Form: M.2 B-key (2280/2260/2242)
  • 5G: NSA/SA Sub-6, LTE Cat 20 fallback
  • SIM: eUICC/eSIM + physical nano-SIM (dual SIM)
  • Interface: USB 3.1, PCIe, QMI/MBIM/AT
  • Pros: eSIM remote provisioning, dual-SIM failover, high speed
  • Cons: eSIM tooling (LPAC/LPA) is complex, firmware can be finicky
Quectel RM520N

Quectel RM500Q-GL

$90–$140
  • Form: M.2 B-key
  • 5G: NSA/SA Sub-6
  • SIM: Physical nano-SIM
  • Interface: USB 3.1
  • Pros: Cheapest 5G option, simple physical SIM
  • Cons: No eSIM, must swap SIM physically to change carrier

LoRaWAN — Long-Range Backup Telemetry

Cellular can fail in remote areas. LoRaWAN provides a low-bandwidth, long-range (1–10 km+) backup telemetry link for failsafe commands and heartbeat.

RAK3172 LoRa Module

$20–$35
  • MCU: STM32WL (LoRa + LoRaWAN)
  • Freq: 868 MHz (EU) / 915 MHz (US)
  • Interface: UART, USB
  • Range: 2–5 km (urban), 10+ km (rural LOS)
  • Pros: Tiny, cheap, ultra-low power
  • Cons: Very low bandwidth (~5 kbps), telemetry only, no video
RAK3172

RAK4631 LoRaWAN Board

$35–$55
  • MCU: nRF52840 + SX1262 LoRa
  • Interface: USB, Arduino-compatible
  • Pros: Arduino ecosystem, BLE + LoRa, easy prototyping
  • Cons: Larger than RAK3172
  • Use: Ground station gateway or drone backup radio
RAK4631

LoRaWAN requires a gateway (The Things Network, ChirpStack, or your own RAK gateway) to bridge to the internet. Use it for RTH trigger, heartbeat, and SMS beacon fallback — not video.

Complete Custom Build Overview & Design

1. Frame Selection

5-inch carbon fiber quad (250–350 mm wheelbase) for BVLOS. Options: iFlight, TBS, ImpulseRC, or custom carbon plates.

2. Power System

4S or 6S LiPo → XT60 → PDB with current sensor → 5V BEC for SBC/FC → ESCs → motors.

3. FC + SBC Integration

Mount FC and SBC on vibration-damping plates. Connect FC TELEM to SBC UART @ 921600 baud. Optionally use a custom PCB integrating both.

4. 5G Modem + Antennas

M.2 5G modem on HAT with 4× MIMO antennas mounted on frame arms (away from motors/ESC noise). Connect to Tailscale VPS.

5. Video System

CSI or USB camera → GStreamer H.264 encode → WebRTC via aiortc → ground station. Target 720p30 @ 2–4 Mbps.

6. RC / Game Controller

USB/Bluetooth Xbox/PS controller → evdev/pygame → MAVLink manual control & RC override via SBC to FC.

7. Failsafes

Dynamic RTH on signal loss / low battery / geofence breach. SMS beacon via Twilio or GSM modem. LoRa backup telemetry.
